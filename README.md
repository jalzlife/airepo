# airepo · AI 学习资料库

> 一个面向云计算解决方案架构师（售前）的个人知识库 —— 以「自包含单文件 HTML」的形式，体系化沉淀 AI / 云 / DevOps 等主题的学习指南。

本仓库（`airepo` = **AI Repository**）用于存放各主题的**自包含单文件 HTML 学习指南**。每个主题一个独立目录，命名遵循统一约定 `<主题>_sty`（`sty` = **study**，学习），浏览器直接打开即可阅读，**无需联网、无需安装任何依赖**。

---

## 🎯 仓库意图

| 维度 | 说明 |
| --- | --- |
| **定位** | AI 时代技术主题的**体系化学习资料库**（非代码仓库，而是知识沉淀库） |
| **内容形态** | 每主题一份**自包含单文件 HTML**：CSS / 图表 / 字体 / 示例全部内嵌，单文件即完整指南 |
| **组织方式** | 一主题一目录，命名 `<主题>_sty`（study 缩写），如 `devops_sty`、`pi_sty` |
| **目标读者** | 云计算售前解决方案架构师、技术顾问，以及需要体系化理解某个技术主题的工程师 |
| **写作风格** | 中文；以读者已有云知识作类比锚点；概念 → 原理 → 特性 → 对比 → 选型建议的完整链路 |

> 一句话：**把「新学一个技术主题」这件事，沉淀为一份可以反复翻阅、离线打开、随时分享的单文件 HTML 指南。**

## ✨ 指南通用特色

所有指南遵循统一的**制作标准**：

- **🎯 面向云计算架构师**：以读者已有的云知识（快照、AMI、API、Auto Scaling、CloudFormation 等）作为类比锚点，让新技术变成旧概念的延伸，降低上手门槛。
- **📦 自包含、零依赖、可离线**：样式、图表引擎、字体全部内嵌在单个 HTML 内，双击即开、部署即用（可放对象存储 + CDN 团队共享）。
- **📊 图文并茂、表格化表达**：每个主题都配有架构图 / 流程图与高密度对比表，便于速查与复习。
- **💻 可运行的代码示例**：命令、配置、脚本均带逐行中文注释，像读带注释的 API 文档。
- **🧭 面向实战的认知框架**：不止罗列知识点，更强调「何时选型、为何如此」的工程判断。
- **🔗 概念互联的讲解方式**：反复用「类似云计算中的 X / 类比 API 调用」的叙事，把新概念挂接到已有知识网络。

## 👤 适用人群

- **云计算解决方案架构师 / 售前 / 技术顾问**：需要在方案中融入 AI 编码代理、CI/CD、IaC、容器化、可观测性等能力，或需要与研发 / 运维 / 平台团队顺畅协作。
- **云平台与运维方向技术人员**：希望补齐从开发到交付、从基础设施到 AI 工具链的全链路认知。
- **开始接触某个新主题的工程师**：想要一份「概念 → 原理 → 特性 → 对比 → 选型」体系化、不碎片化的入门材料。
- **任何能读懂 Markdown / API 文档、想系统了解某主题的人**。

> 前置要求很低：会使用浏览器即可阅读；若想动手练习示例，具备基础的命令行与阅读能力更佳。

## 🚀 如何使用

**无需构建、无需安装依赖，也不需要网络**：

1. 进入对应主题目录，下载其中的 `.html` 文件；
2. 用任意现代浏览器（Chrome / Edge / Firefox / Safari）双击打开；
3. 使用页面左侧「目录」栏在章节间快速跳转，按编号顺序阅读。

也可以将 HTML 文件部署到任意静态站点 / 对象存储（如 S3 + CloudFront、OSS + CDN）上，作为团队内部学习资料在线分享；或使用浏览器「打印 / 另存为 PDF」导出归档。
